# Redesign preview (sample only)

This `/preview/` directory is a **design sample** for the Ustad Hub professional
redesign project. It is NOT linked from any live page and changes nothing
about the existing site.

- `index.html` — redesigned homepage mock using real site content
  (latest real post titles/dates/URLs from `posts.json`)
- `preview.css` — sample stylesheet (golden + navy, Poppins, mobile-first)

Guardrails: preview branch only, no production changes without approval.
